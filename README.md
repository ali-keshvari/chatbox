# 🤖 سامانه هوشمند چت‌باکس و تحلیل اسناد با ASP.NET Core 10 و Ollama

این پروژه یک وب‌اپلیکیشن کامل و حرفه‌ای با **ASP.NET Core 10** (`net10.0`) است که به کاربر اجازه می‌دهد انواع فایل‌های متنی و اسناد اداری (**Word ،PDF ،Text و...**) را بارگذاری کرده و همراه با دستور (Prompt) دلخواه به مدل‌های زبانی محلی مستقر روی **Ollama** (مانند `qwen3.8`) ارسال نماید و نتایج را مشاهده کند. کلیه گفتگوها، پیام‌ها و فایل‌های استخراج‌شده در دیتابیس **SQL Server (SSMS)** با **Entity Framework Core** ذخیره می‌شوند.

---

## ✨ ویژگی‌های کلیدی پروژه

1. **فناوری مدرن:**
   - توسعه داده شده با **.NET 10.0** (`net10.0`).
   - ساختار Solution کامل (`ChatBox.sln`).

2. **پردازش و استخراج خودکار متن اسناد:**
   - پشتیبانی از فایل‌های **PDF** با استفاده از کتابخانه خالص `UglyToad.PdfPig`.
   - پشتیبانی از فایل‌های **Word** (`.docx` و `.doc`) با استفاده از `DocumentFormat.OpenXml` همراه با استخراج جدول‌ها و پاراگراف‌ها.
   - پشتیبانی از فایل‌های متنی (`.txt`, `.md`, `.json`, `.csv`, `.xml`, `.log`, `.yaml`, کدها و...).
   - امکان بارگذاری چندین سند به طور همزمان (مثلاً دو فایل Word جهت مقایسه تفاوت‌ها، مفاد قرارداد یا استخراج امضاکننده).

3. **ارتباط با Ollama محلی:**
   - خواندن خودکار لیست مدل‌های نصب‌شده روی سیستم از طریق `GET http://localhost:11434/api/tags`.
   - نمایش مدل‌ها در یک Dropdown در نوار بالای نرم‌افزار با قابلیت انتخاب توسط کاربر.
   - **قانون قطعی عدم تلاش مجدد (No Retry):** بر اساس درخواست شما، در صورتی که مدلی روی سیستم یافت نشود یا سرویس در دسترس نباشد، **هیچ Retry انجام نمی‌شود** و بلافاصله پیام خطای شفاف به کاربر اعلام می‌گردد.
   - امکان وارد کردن دستی نام مدل دلخواه (مانند `qwen3.8`).

4. **پایگاه داده و سابقه گفتگوها (SSMS با EF Core):**
   - ذخیره خودکار جداول `Conversations`، `ChatMessages` و `FileAttachments` (شامل متن استخراج شده اسناد) در دیتابیس `ChatBoxDb`.
   - ایجاد خودکار پایگاه داده در اجرای اول با `Database.EnsureCreated()`.
   - ارائه اسکریپت `DatabaseSetup.sql` جهت اجرای دستی در SQL Server Management Studio در صورت نیاز.
   - امکان مشاهده تاریخچه چت‌های قبلی در منوی کناری (Sidebar)، جستجو در گفتگوها و حذف گفتگو.

5. **رابط کاربری حرفه‌ای و مدرن (UI/UX):**
   - طراحی اختصاصی راست‌چین (RTL) با فونت وزیرمتن (Vazirmatn).
   - تم تیره (Dark Mode) و تم روشن (Light Mode) با قابلیت سوئیچ سریع.
   - رندرینگ کامل مارک‌داون (Markdown) به همراه جدول، لیست و هایلایت کد با دکمه کپی پاسخ.
   - پیش‌نمایش فایل‌های پیوست‌شده (File Chips) با آیکون نوع فایل و حجم، به همراه قابلیت Drag & Drop.
   - نشانگر پویای وضعیت اتصال به Ollama و انیمیشن پردازش پاسخ (Thinking Dots).

## 🚀 راهنمای اجرا

### ۱. تنظیم پایگاه داده در `appsettings.json`
کانکشن استرینگ SQL Server در فایل [ChatBox.Web/appsettings.json](file:///d:/ChatBox/ChatBox.Web/appsettings.json) قرار دارد:
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=ChatBoxDb;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true"
  },
  "Ollama": {
    "BaseUrl": "http://localhost:11434",
    "DefaultModel": "qwen3.8",
    "TimeoutSeconds": 180,
    "TagsTimeoutSeconds": 3
  }
}
```
> در صورت استفاده از نام Instance خاص در سیستم خود (مانند `localhost\SQLEXPRESS`)، مقدار `Server` را مطابق با سیستم خود تنظیم کنید.

### ۲. اجرای پروژه
برای اجرای پروژه بدون نیاز به انجام تست‌های خودکار (تست‌ها بر عهده خودتان است):
```bash
cd ChatBox.Web
dotnet run
```
سپس مرورگر را باز کرده و به آدرس نمایش‌داده شده (مثلاً `https://localhost:7xxx` یا `http://localhost:5xxx`) مراجعه فرمایید.

### ۳. بررسی مدل در Ollama
برای نصب مدل `qwen3.8` در اولاما می‌توانید دستور زیر را در ترمینال اجرا کنید:
```bash
ollama run qwen3.8
```
یا هر مدل دیگری که مد نظر دارید. در صورت نصب نبودن مدل، چت‌باکس بدون معطلی و بدون retry خطای در دسترس نبودن مدل را نمایش خواهد داد.
